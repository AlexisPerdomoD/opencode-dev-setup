# Convenciones de GitHub

Ver skill `github-issues` para detalle completo.

## Resumen

- **Sub-issues**: siempre GraphQL con `parentIssueId`.
- **Prefijos**: `feat:`, `fix:`, `refactor:`, `style:`, `chore:`, `docs:`, `test:`, `revert:`.
- **Labels**: `epic` para padres, `blocked`/`in-progress` según estado.
- **Commits**: atómicos, pequeños, prefijo de tipo.

## Importante

- `github_issue_write` con `method: "create"` — no `create_issue` sueltas.
- Frontend tasks → repo de frontend.
