# GitHub Workflow

## Convenciones de GitHub

Ver skill `github-issues`.

## Obtener contexto al inicio de sesión

1. **Proyecto específico**: leer `README.md`, `AGENTS.md` (si existe), `doc/` del repo.
2. **Estructura del código**: `glob` y `grep` para navegar.
3. **Equipos y repos**: `github_get_me`, `github_get_teams`, `github_search_repositories`.

## Reglas de contexto

- **No asumir** que el contexto de una sesión anterior aplica a la actual.
- **Preguntar** si las instrucciones del usuario no están claras.
- **Notas del usuario** sobre scope, prioridades o decisiones → son de esa sesión, no globales.

## Planning y Commits

- Commits: atómicos, una sola preocupación, prefijo de tipo.
- Planning: proponer primero, esperar aprobación antes de ejecutar.
- Issues: skill `github-issues`.
