# Cómo obtener contexto

## Proyecto

- `README.md`, `AGENTS.md` si existe, `doc/` — configuración y arquitectura.
- `glob` + `grep` — estructura y navegación del codebase.
- `read` — archivos relevantes.

## GitHub y equipos

- `github_get_me` — identidad y permisos.
- `github_get_teams` — equipos accesibles.
- `github_search_repositories` — encontrar repos.
- `github_list_issues`, `github_list_pull_requests` — estado de trabajo.

## Código

- `task` con agente `explore` — búsquedas amplias.
- `grep` / `glob` — navegación directa.

## Notas

Instrucciones del usuario sobre scope o prioridades = sesión actual, no globales. Preguntar si no está claro.
